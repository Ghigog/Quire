# Site assets — Pneumaturgy studio site

Art collected from ten repositories for the studio site, prepared for the web.
16 files, 1.8 MB total, nothing over 400 KB.

Logos are 512×512 PNG. Images are max 1600 px on the long edge, JPG where
photographic and PNG where they carry transparency or flat colour. No WebP.

This folder is a hand-over, not a publication. Nothing here has been pushed to
any repository other than this branch.

## Things you need to know before using these

### Quire has no art at all
There is not one image file in the repository — no logo, no icon, no
screenshot, and no Android app module that could produce one. Nothing was
prepared for it. It needs art made.

### Shipwright is not a Pneumaturgy project
`Ghigog/Shipwright` is a fork of `HarbourMasters/Shipwright` — Ship of
Harkinian, the Ocarina of Time PC port. Its art is that project's branding
(`docs/shiptitle.*.png`) and game textures derived from the original game.
Nothing was taken from it. Putting it on the studio site under the `sevensages`
slug would present someone else's project, and Nintendo-derived assets, as
studio work. If Seven Sages is a separate project of yours, it is in a
different repository than the one on the list.

### Orison's mark is white and will vanish on a light page
`orison-logo.png` is a white line sigil on transparency — average luminance of
its visible pixels is 220/255. It is correct for a dark background and
effectively invisible on a white card. I have left it exactly as it is in the
repository rather than inventing a backdrop for it. Either place it on a dark
plate, or have a dark-ink version drawn.

### Three logos are not transparent
`mollusk-logo.png` (near-white `#f4f5fa` ground), `cerdo-logo.png` (cream
ground) and, unavoidably, anything derived from them carry a solid background
from the source file. They sit fine on a light page and will show a visible box
on a dark one. Keying the background out would have left halos on the soft
gradients, so I did not.

### Cerdo's logo is a 4× upscale
The project's canonical icon (`project.godot` → `config/icon`) is
`Assets/cerdito.png` at **128×128**. There is no larger version in the
repository. The APK ships a 432×432 adaptive-icon foreground, but it is a
washed-out grey auto-generation by the Godot exporter and looks worse. So
`cerdo-logo.png` is the 128 px original enlarged with Lanczos. The art is flat
enough that it holds up, but it is not a true 512 px asset.

### Theory Forge has no logo and no screenshot
`lol-theory` contains only a 343×361 decorative graphic, which is below your
400 px floor and is what `theoryforge-01.png` is. There is no logo file.

I tried to produce a real screenshot: the app builds and the dev server runs,
but it fetches all its champion and item data from
`cdn.merakianalytics.com` and `ddragon.leagueoflegends.com`, and both are
blocked by this environment's egress policy. The app renders
`CONNECTION FAILED` and nothing else. A screenshot has to be taken from a
machine that can reach those two hosts.

### Two files I generated rather than found
Flagging these because they are not files that exist in any repository:

- `vapor-02.jpg` — Vapor's repo ships its Claude Design canvas export
  (`design/Vapor Music v2 - Daylight.dc.html`). I rendered it in a browser and
  cropped two phone screens from it. The canvas runtime that binds data is
  deliberately not committed, so 43 unbound `{{ placeholders }}` appear across
  the page; the crop is from a region that has none. Check it reads as you
  intend before it goes on the site — it is a design mock, not a running app.
- `cerdo-01.png` — rasterised from the repo's `dice6.svg`. Cerdo's three raster
  backgrounds are an empty gradient, a blank card frame and a dot texture, none
  of which show anything.

### A bonus: the studio's own logo
`pneumaturgy-logo.png` is the Pneumaturgy mark, which is sitting in
`by_jove_godot/assets/art/images/PneumaturgyLogo.png`. You did not ask for it
and it belongs to no project on the list, but a studio site probably wants it,
so it is included. Delete it if you have a better copy.

### No release attachments, no remotely-hosted images
None of the five repositories reachable through the GitHub API
(Quire, mollusk, navi-agent, orison, lol-theory) has any release. No README in
any of the ten embeds an externally-hosted image; the only remote references
are shields.io badges in `lol-theory` and `lytra`, which are generated badges
rather than art, so there is no URL worth recording.

### Godot stock icons, skipped
`navi-agent/icon.svg` and `orison/resources/assets/icon.svg` are byte-identical
(md5 `a16f2eed…`) and are the default Godot engine icon, not project art.
Neither was used.
